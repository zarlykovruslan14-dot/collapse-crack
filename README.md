# Collapse Launcher 6.0

Лаунчер Minecraft Bedrock для Windows 10/11. Автор проекта — @bestphpp. Канал — https://t.me/mcbeforandroid.

## Возможности

- Новый интерфейс WPF, выбор своего фона и поиск установленных версий.
- Каталог UWP и GDK, загрузка и подготовка сборки одной кнопкой.
- Библиотека .mcpack / .zip, активный список и порядок ресурспаков.
- Библиотека PNG-скинов Classic / Slim с установкой в найденные профили Bedrock.
- Отключение VSync и ограничения FPS через настройки игры.
- Загрузка обновления из GitHub Releases, проверка SHA-256, замена EXE и перезапуск.

## Проверенный объём

Проверены импорт и отключение ресурспаков на тестовом профиле, сохранение сторонних наборов, запись настроек FPS, создание набора скина, загрузка каталога, получение ссылки Microsoft на APPX и доступ к потоку пакета. Обновление с заменой и перезапуском проверено на тестовых EXE. Все экраны отрисованы и проверены.

Полная установка GDK и автоматический выбор скина в игре пока не подтверждены на реальном запуске. Для подготовки GDK используются службы Windows / Xbox и ключи от установленного через Microsoft Store Minecraft. Смена аккаунта Xbox выполняется в самой игре. В лаунчере нет переключения игровых сессий Microsoft.

## Данные

Библиотека и настройки находятся в %LOCALAPPDATA%\Collapse Launcher. Перед изменением ресурспаков, скина и FPS закрой Minecraft. Активный список синхронизируется с найденными папками данных UWP, GDK, Shared и переносимых сборок при запуске. Миры не редактируются.

## Сборка

Запусти Build.ps1 в Windows PowerShell из этой папки. Используется установленный в Windows .NET Framework 4.8 и WPF. Результат — Collapse Launcher.exe. Изображение landscape.png создано для проекта средствами ImageGen.

## Публикация обновления

Согласуй AssemblyVersion, AssemblyFileVersion и Updater.Current, собери EXE и опубликуй обычный GitHub Release с тегом вида v6.1.0. Прикрепи EXE. Лаунчер принимает контрольную сумму SHA-256 из поля digest GitHub API. Настройка автообновления включена по умолчанию и доступна пользователю.
